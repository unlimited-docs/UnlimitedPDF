## How to sign

Sign once, on your first pull request: add a comment of its own that says exactly

```

```

Your signature covers this version of the Agreement. If the Agreement changes to a new version, you sign again on your next pull request.

Signing records your GitHub username and user ID, the pull request number, the comment, and the time, in the `cla-signatures` branch of this repository, which is public. Questions about this Agreement go to [support@unlimitedpdf.com](mailto:support@unlimitedpdf.com).
